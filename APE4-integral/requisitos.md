# Requisitos medibles

| Id | Requisito | Medida de cumplimiento |
|---|---|---|
| R1 | El usuario debe poder iniciar el agendamiento desde la pantalla de inicio. | Menos de 10 segundos y 1 clic desde el inicio. |
| R2 | El usuario debe elegir especialidad, médico, fecha y hora. | Las 4 selecciones se completan en 4 pasos o menos. |
| R3 | Los horarios ocupados deben verse antes de elegirlos. | 100 % de horas ocupadas deshabilitadas y marcadas con texto. |
| R4 | El formulario debe validar nombre y teléfono con mensajes claros. | Cada error dice qué campo y cómo corregirlo. |
| R5 | Ante un error de reserva el usuario debe recuperarse sin perder datos. | Los datos escritos se conservan al reintentar. |
| R6 | Al finalizar debe verse una confirmación con código de cita. | Mensaje de éxito con código en menos de 3 segundos tras confirmar. |

Accesibilidad aplicada: foco visible, uso completo con teclado, mensajes con aria-live, texto de 18 px y botones de 44 px o más.
